Screenshot → Clipboard Family

Three browser extensions built on one promise: one click and the image is on your clipboard. No editor, no save dialog, no download, no account, no server. Each sibling captures from a different source, and they share an icon language so you can tell them apart at a glance.

Quick Screenshot → Clipboard — the eldest · visible tab

Click the icon and whatever fills the tab right now becomes a PNG on your clipboard. The one that set the family's rule. It also has a twin: the same extension ported to Firefox.

Stitch Screenshot → Clipboard — the middle child · full page

One click scrolls the whole page, stitches every section into a single tall PNG and copies it. For long articles, entire conversations and bug reports that never fit on one screen.

Frame Screenshot → Clipboard — the youngest · video frame

Hover any HTML5 video and the current frame is copied at the video's own resolution — only the video, never the page around it. Store listing on the way; today it loads unpacked.

How I Think

I build software with clarity as the first principle. Code should communicate intent. Interfaces should feel intentional, not accidentally complex. Users should understand what's possible without reading a manual.

  • Clarity first. Clean code, clear interfaces, obvious UX. If something needs explanation, simplify it.
  • Utility over novelty. Tools should solve real problems. Practicality matters more than impressiveness.
  • Careful interfaces. Whitespace is intentional. Typography serves hierarchy. Every visual choice has purpose.
  • Technical confidence. Learn how things actually work. Understand performance, reliability, and constraints.
  • Small tools win. Focused scope means finished. One small well-built tool beats ten abandoned ideas.
  • Learning by building. Reading teaches concepts. Building teaches wisdom. Real projects reveal what matters.
  • Thoughtful execution. Details accumulate. Attention to spacing, rhythm, and polish separates good from mediocre.
